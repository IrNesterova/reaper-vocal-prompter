# Vocal Prompter для REAPER

[![tests](https://github.com/IrNesterova/reaper-vocal-prompter/actions/workflows/tests.yml/badge.svg)](https://github.com/IrNesterova/reaper-vocal-prompter/actions/workflows/tests.yml)

**[English version →](README.md)** · [Журнал изменений](CHANGELOG.md)

Суфлёр для записи вокала в REAPER. Во время записи или воспроизведения крупно показывает текущую строку текста, а под ней следующие — не нужно отвлекаться на другое окно или телефон.

- Вставь текст, открой `.txt` / `.lrc` или **найди онлайн** ([LRCLIB](https://lrclib.net)) — часто сразу с таймингами
- **Песни исполнителя списком**: впиши только исполнителя, выбери песню, выбери версию текста
- **Тайминги тапом** под минус (Enter / T в начале каждой строки), точная подгонка перетаскиванием
- **Пометки над и под словами** — дыхание, акценты, динамика или свои значки
- Текст, название и тайминги **хранятся в каждом проекте** — открываешь другой проект, и подтягивается его текст
- Крупный текст по центру, размер на выбор, **полупрозрачное окно**, компактный режим «только суфлёр»
- **Темы и цвета**: тёмная / «Полночь» / светлая, 8 цветов акцента или свой
- Интерфейс на **русском и английском**

## Что нужно

- REAPER (Windows или macOS)
- [ReaImGui](https://forum.cockos.com/showthread.php?t=250419) 0.9 или новее
- `curl` для онлайн-поиска — уже есть в Windows 10+ и macOS

## Установка

### 1. Поставить ReaPack (если нет меню *Extensions*)

1. Скачай ReaPack под свою систему с [reapack.com](https://reapack.com) (для Windows — `reaper_reapack-x64.dll`).
2. В REAPER: **Options → Show REAPER resource path in explorer/finder…**
3. Положи файл в папку **UserPlugins** и перезапусти REAPER.

### 2. Поставить ReaImGui

1. **Extensions → ReaPack → Browse packages…**
2. Найди `ReaImGui`, правый клик по **«ReaImGui: ReaScript binding for Dear ImGui»** (автор cfillion) → **Install** → **Apply**.
3. Перезапусти REAPER.

### 3. Добавить скрипт

1. Скачай [`Vocal_Prompter.lua`](Vocal_Prompter.lua).
2. **Actions → Show action list → New action… → Load ReaScript…** и выбери файл.
3. По желанию повесь на хоткей или кнопку тулбара.

Чтобы обновить — замени файл новой версией и перезапусти скрипт.

## Как пользоваться

В окне четыре вкладки.

### Текст

- **Песня** — название, которое видно сверху в суфлёре. Заполняется само: из поиска, из тегов `[ar:]`/`[ti:]` в LRC или из имени файла.
- **Поле текста** — вставь обычный текст или LRC с таймингами `[мм:сс.xx]` и нажми **Применить**. Пустые строки пропускаются. **Открыть файл…** загружает `.txt` / `.lrc`.
- **Поиск онлайн**
  - *Исполнитель + название* → список версий текста. `[с таймингами]` — тайминги уже есть.
  - *Только исполнитель* → его песни (из LRCLIB и iTunes Search API) по алфавиту, с фильтром. Клик по песне → версии → клик по версии загружает текст. **← к песням** возвращает к списку.

### Синхро

- **Начало песни в проекте** — где на таймлайне начинается песня. Нужно, если минус стоит не с нуля или скачанные тайминги немного разъехались.
- **Показывать раньше на** — насколько заранее появляется строка (по умолчанию 0,3 с), чтобы успеть вдохнуть.
- **TAP** (или **Enter** / **T**) — включи минус и тапай в начале каждой строки. Клик по строке в списке — перетапать с неё. Время можно подогнать перетаскиванием; **>** переносит курсор к строке.
- **В маркеры** — расставляет строки маркерами на таймлайне.
- **Режим пометок** — значки над или под словами (дыхание **V**, **↑ ↓**, **~**, **>**, **!**, **p**, **f** или свой: впиши и нажми **Добавить**). Выбери значок и «Над словом» / «Под словом», потом кликай по словам в списке. Повторный клик убирает значок, **Ластик** стирает всё со слова, правый клик по своему значку убирает его из набора. Пометки сохраняются в проекте.

### Суфлёр

Сверху название песни, индикатор REC и время; в центре — предыдущая строка (бледно), **текущая** (крупно), полоска до следующей и две следующие строки.

Кнопка **Вид** (справа сверху) или **правый клик в любом месте окна** → быстрые настройки вида:

- **Размер текста** — 4 ступени
- **Непрозрачность фона** — прозрачность видна, когда окно откреплено от дока
- **Только суфлёр** — прячет вкладки; удобно держать маленьким окном поверх REAPER во время записи

Кнопка **RU · en** справа от вкладок переключает язык интерфейса.

### Настройки

- **Тема** — тёмная, «Полночь» (тёмно-синяя) или светлая
- **Цвет акцента** — 8 готовых или **свой цвет** (палитра); им окрашены кнопки, полоска прогресса и подсветка. Текст на акцентных кнопках сам становится тёмным или светлым, чтобы читался
- **Текущая строка цветом акцента** — подсветить строку, которую поёшь
- **Суфлёр** — размер текста, непрозрачность фона, режим «только суфлёр», показ пометок
- **Язык интерфейса**, **Сбросить настройки**

Настройки общие для всех проектов. Чтобы выйти из режима «только суфлёр», кликни по окну правой кнопкой и сними галочку.

## Где хранятся данные

- Текст, название, тайминги и сдвиг — в самом проекте (`.rpp`) через project ExtState. После загрузки текста сохрани проект (Ctrl+S).
- Язык и настройки вида — глобально в ExtState REAPER.
- Онлайн-поиск отправляет только введённые исполнителя/название на `lrclib.net` и `itunes.apple.com`. Временные файлы лежат в `<папка ресурсов REAPER>/Data/VocalPrompter`.

## Если что-то не так

| Проблема | Решение |
|---|---|
| Нет меню *Extensions* | Не установлен ReaPack — см. шаг 1 |
| «Для суфлёра нужен ReaImGui» | Поставь ReaImGui (шаг 2) и перезапусти REAPER |
| Поиск: «сервер не ответил» / ошибка сети | lrclib.net может быть недоступен из твоей сети — проверь в браузере; может помочь VPN. Текст всегда можно вставить вручную |
| Строки появляются рано/поздно | Подкрути **Начало песни в проекте** или **Показывать раньше на** во вкладке «Синхро» |
| Не видно прозрачности | Открепи окно (вкладка «Синхро» → **Открепить**) |
| Не получается выйти из режима «только суфлёр» | Правый клик по окну → сними галочку **Только суфлёр** |

## Тесты

Тесты запускают скрипт вне REAPER — на моках API REAPER и **строгом моке ReaImGui**, который знает только функции, доступные скриптам с API 0.9 (список `tests/reaimgui_api_0.9.txt` сгенерирован из исходников ReaImGui скриптом `tests/tools/gen_api_list.py`). Обращение к несуществующей функции падает точно так же, как в настоящем ReaImGui, а в каждом кадре проверяется парность Begin/End и Push/Pop.

Что проверяется: разбор текста и LRC, JSON, локализация, тайминги и тап, хранение в проекте и переключение проектов, маркеры, фоновый поиск (Windows `.bat`/`.vbs`, macOS `.sh`), список песен исполнителя, темы и цвета акцента, возврат размера окна после сворачивания, отрисовка всех вкладок во всех состояниях, темах и на обоих языках. Простая модель раскладки проверяет, что ни одна кнопка не вылезает за край окна шириной от 260 px.

```sh
lua5.4 tests/run_tests.lua
```

На GitHub тесты запускаются автоматически при каждом пуше.
